Netmon apt repository

Debian packages that put Netmon, the home network monitor, on a Pi Hero device: netmon-scanner (the scanner, publishing over MQTT) and netmon-display (the web display in a kiosk). The packages, their source, and the device files that install them on first boot live at github.com/bkahlert/netmon.

Add the repository

The flat repository at /netmon/apt is signed with the key whose fingerprint is 98EF 4196 9A24 4534 0B87 6133 F95F 4C33 F6D8 E717. Device files embed it; on an existing system:

curl -fsSL https://bkahlert.github.io/netmon/apt/netmon-apt.asc | sudo tee /etc/apt/keyrings/netmon.asc >/dev/null
sudo tee /etc/apt/sources.list.d/netmon.sources >/dev/null <<'SOURCES'
Types: deb
URIs: https://bkahlert.github.io/netmon/apt
Suites: ./
Signed-By: /etc/apt/keyrings/netmon.asc
SOURCES
sudo apt update && sudo apt install netmon-scanner netmon-display
